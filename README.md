# MaruBatsuGame-Tic Tac Toe

## C++で制作したシンプルな〇×ゲームです。

### 動作環境

Windows

Visual Studio（ソースコードからビルドする場合）

### ビルド方法

MaruBatsuGame.vcxproj をVisual Studioで開きます。

構成を Debug、プラットフォームを x64 に設定します。

ビルドを実行します。

### ダウンロード

完成版は Releases からダウンロードできます。

### 注意事項

・ コンソールアプリです
・ ゲームが終了次第、プログラムも終了するため、勝敗の判定が行われません。
　 Visual Studioで動かす場合、勝敗の判定をするプログラムが入っているため勝敗が判定されます。
